# 紫微命盘：本地规则首版

项目仓库：[xuxiaohang007-prog/ming](https://github.com/xuxiaohang007-prog/ming)。仓库包含运行源码、启动入口、锁定依赖清单与必要测试源码，不包含密钥、已安装依赖、构建产物、历史报告、截图或本机备份原件。本机既有归档仍保留在 `算命备份数据`；Git 只允许提交其中的 `tests`、两份 Playwright 配置和独立 TypeScript 配置，不会删除其他本机资料。

当前版本 `0.4.0`：第十五步补齐独立运限规则报告、五章阅读、引用回溯与专用打印，保留本命六章报告和前两步的数据／安全功能。早期步骤记录中的缺项与版本是历史状态，最新功能以第十五步记录和本文件为准。

## 交付范围

公历／农历出生输入、早子／晚子与闰月校验、iztro 真实十二宫排盘、宫位详情及依据回溯、按公历分析日期查看真实大限／童限与流年资料、六章本地规则报告、真实请求状态与取消／重试、桌面／手机阅读、浏览器打印及另存 PDF。

运限面板展示计算资料，并可生成所选层级的独立本地规则报告，不改变上方本命星曜或已有六章报告，不作吉凶评分、寿命判断或具体事件预测。独立报告是产品预置文化提示，不是 iztro 官方解释，也不是大模型生成。

默认按钮为“生成本地解读”。**不需要 API 密钥，不安装或下载模型，未调用大模型。**规则报告是本项目十四主星预置规则的参考说明，不是 iztro 官方解读，不证明预测未来准确。自由问题只保留为主题资料，不作语义回答；不提供医疗、投资等决策建议。

保留的云端选项是旧接口的兼容入口，不会默认启用，也不会在本地模式失败后偷偷调用。真实云端解读需要单独配置服务端密钥，不属于本次免密钥交付验收。

## 本机启动

本次验证环境：Windows、Node `24.14.0`、npm `11.9.0`、Microsoft Edge。最低 Node 要求 `20.9.0`，启动脚本会提前检查；其他 Node 版本仍需实际运行验证。首次安装 npm 依赖需要联网；安装完成后，本地规则主流程不访问外部模型或字体服务。

在项目目录执行：

```powershell
# 从 GitHub 首次获取并启动（需要 Git、Node.js 和 npm）
git clone https://github.com/xuxiaohang007-prog/ming.git
cd ming
.\启动系统.ps1 -InstallDependencies

# 已安装依赖时：构建后启动，仅绑定本机地址
.\启动系统.ps1

# 首次安装或按锁文件恢复依赖
.\启动系统.ps1 -InstallDependencies

# 修改代码时使用开发模式
.\启动系统.ps1 -Development

# 已有经过验证的最新生产构建时跳过构建
.\启动系统.ps1 -SkipBuild

# 只检查路径与依赖，不启动服务、不安装软件
.\启动系统.ps1 -CheckOnly
```

打开 `http://127.0.0.1:3000/`，按 Ctrl+C 停止服务。端口被占用时，脚本不会结束其他进程；可停止原服务，或使用 `-Port 3001`。如果系统限制执行脚本，可直接执行以下等价命令，不必修改机器级执行策略：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run start -- --hostname 127.0.0.1 --port 3000
```

生产服务与回归测试不要同时运行；开发／测试会修改 `.next`，之后需重新构建再启动生产服务。

## 使用与隐私

1. 填写排盘性别、出生日期及时间；姓名和地点选填。时间按 UTC+8，地点不用于真太阳时校正。
2. 生成命盘并核对出生档案；点击任一宫位查看星曜与三方四正。
3. 选择阅读主题并点击“生成本地解读”。可取消或重试，不会为了动画人为延迟结果。
4. 报告摘要卡与六章正文分开展示，依据可返回实际宫位，报告仍可重新打开。
5. 点击“打印／另存 PDF”，选择 A4。应用打印样式包含页码；浏览器的额外页眉页脚建议关闭，避免重复。PDF 含出生档案，请谨慎保存与分享。

出生信息与报告不持久保存到数据库或浏览器存储，刷新页面会清除本次档案。浏览器仅保存本地／示例模式偏好。修改出生信息或新建命盘会清除旧命盘和报告。接口设置 `no-store`，无在线分享或历史档案服务。

## 查看运限资料

生成命盘后，在盘面下方展开“时间切片 / 运限资料”，选择“公历分析日期”，点击“获取运限资料”。默认日期取 UTC+8 当天；若生日在未来则选生日当天，不自动发出计算请求。

可切换流年与大限／童限，查看虚岁、干支、十二宫流曜、四化及十二个大限区间。四化和宫位按钮定位实际本命位置，上方本命星曜与四化保持原样。流年和虚岁以农历正月初一为界，不按公历元旦、立春或生日切换。

本步分析日期限真实的 1900 至 2100 年公历日期，不能早于公历生日，且必须在库返回的十二个大限支持范围内。尚未起大限时显示“童限”，不会补造十年区间。区间年份为名义农历年份范围，不是精确公历起止日，也不是寿命或事件预测。

改日期会清除旧资料及运限报告；请求可取消，15 秒未完成会提示超时。资料只在当前命盘页面内存中存在，进入本命报告或修改出生信息时会结束请求、清除资料，重新返回后可再次获取。六章报告与其打印仍仅覆盖本命盘，不自动纳入运限数据。

获取运限资料后选择流年或大限／童限，点击“生成运限规则报告”。独立窗口提供范围与时间、运限命宫、主题宫位、四化定位、核对行动五章。计算事实和产品规则参考分开展示；引用会返回当前运限层或实际本命星曜，不把流曜冒充本命星体。

关闭阅读窗口后可“查看已有运限报告”。换日期、切换层级或重新获取资料会使旧报告失效。独立窗口内的“打印运限报告／另存 PDF”只打印当前报告；关闭窗口后恢复本命页面的原打印行为。打印包含个人称呼、出生条件和分析日期，请谨慎保存与分享。没有历史档案或在线分享功能。

## 开发与测试

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
npm.cmd audit
npm.cmd audit --omit=dev
npm.cmd run audit:security
```

生产构建启动在 3000 端口后，可在另一终端运行 `npm.cmd run test:production`，直接验证生产页面和真实接口，不启动开发服务器。测试及 Playwright 配置已移至 `算命备份数据`，npm 测试命令保持可用。此配置执行三种宽度的主流程、HTTP 联调、安全／运行环境专项以及运限专项，新记录位于 `算命备份数据\新测试结果\生产`；部分边界和异常用单元模拟核对，不代表生产中真的发生过供应商故障。

`audit:security` 对全部依赖执行审计，发现中等级及以上问题时返回失败；它需要联网，不在正常离线启动时自动执行。版本发布前应依次通过审计、类型检查、完整回归、构建和生产联调。测试中的 Windows PowerShell 执行策略设置仅作用于一次性子进程，不修改系统策略。

测试使用本机 Edge，在 `127.0.0.1:3100` 自动启动和关闭测试服务；运行前确保没有旧测试服务器。测试不会用真实 API 密钥。云端异常／流式协议采用受控模拟；本地规则与排盘接口使用真实计算。

PDF 验收额外需要 Python 的 `pypdf`、`pdfplumber`。本机默认使用 Codex 捆绑的 Python；其他环境可设置 `PDF_TEST_PYTHON` 为已安装上述模块的 Python 可执行文件绝对路径。不要将其设置成包含额外参数的命令。新截图与诊断 PDF 自动生成在 `算命备份数据\新测试结果\回归`，后续测试会覆盖同类新结果；这些生成产物不会提交到 Git。本机旧测试结果和阶段截图保留在归档目录，不随仓库分发。

## 已知限制与上线门槛

当前为**本机首版**，不是已完成安全验收的公开互联网服务。2026-10-11 第十三步通过有验证的 Next／Tailwind 迁移解决此前 9 项已知依赖问题；锁文件重新安装后，全量与生产依赖审计均为 0 项。未执行 `npm audit fix --force`，未添加未经验证的依赖覆盖。审计是当前公告数据库的结果，不保证未来没有新漏洞，应定期重查。

页面和接口配置基础安全响应头：禁用 MIME 嗅探、Referrer、外部页面嵌入和相机／麦克风／地理位置权限，声明本机资源仅供同源读取，并关闭框架标识响应头。出生接口的 no-store 继续保留；这些措施不等于完整的认证或 CSRF 防护。

公开上线前仍需正式评估安全风险、补充访问控制、CSRF 防护、严格 CSP 与服务级限流、确定个人信息政策、验证部署平台的流式响应及超时限制，并完成真实模型调用验收（如果未来启用）。本次未进行云端实调、打印机实物测试或公开部署。PDF 自动化实测基于本机 Edge，其他浏览器需单独验收。

暂不包含真实大模型运限解读、流月／流日／流时界面、历史档案、自由追问、海外时区／夏令时／真太阳时修正、流派切换、专用 PDF 服务与分享链接。本机历史演示和旧云端配置示例仅保留在归档目录，不随仓库分发，也不作为正式服务入口；默认本地规则不需要环境密钥。
